Brad DeLong CDSS Weblog Archive Project
Work to date — Emily Liang, UC Berkeley Data Discovery
Updated: 10 November 2026

This file is a record of what has been done so far: sources used,
findings, deliverables, and what is still open. Original archive ZIPs
were never modified.


1. Project
----------
Preserve and organize Brad DeLong’s weblog archive across eras
(pre-TypePad / Movable Type, TypePad, later WordPress/Substack),
with enough metadata and provenance to rebuild a continuous,
queryable historical archive.

Immediate assigned work has been the Movable Type HTML archives
(2001–2005), then a metadata table for matching local files to
historical URLs.

3. Important findings
---------------------
Filenames are not globally unique.
  000001.html appears in multiple archive folders and is different
  posts. The identifier is the full path inside the ZIP, e.g.
  2005_archives/000082.html

The “2005” ZIP includes late 2004 posts.
  First 2005 inventory dates: 2004-09-10 through 2005-12-21.

Dates must be taken only from:
  Posted by DeLong at ...
Not from:
  Tracked on ...          (trackbacks)
  Posted by: [someone]    (comments)

XML files in the 2005 ZIP are RSS 0.91 trackback sidecars, not full
Movable Type exports. They often contain the post title, a historical
URL, a short excerpt, and trackback items (sometimes later spam).
The XML number does not always match the HTML filename
(example: 76.xml belongs with 000082.html, not 000076.html).
Many posts have no XML sidecar (740 XML vs 1,927 posts).

No standalone image/PDF files are stored in either ZIP.
  HTML posts reference images and PDFs by URL only. Those URLs were
  kept as placeholders.

2003_archives--July 1 2003 is a snapshot.
  1,346 numeric HTML files, all also present in 2003_archives.
  Not double-counted in lists or the database.

Some “Posted by” dates are 1986–2000.
  These look like paper/publication dates typed into Movable Type,
  not the start of daily blogging. They were kept in a side list,
  not discarded.

The live Movable Type host is down.
  http://www.j-bradford-delong.net/movable_type/... times out.
  Historical copies are on the Wayback Machine.

6. Phase 3 — URL-matching metadata table
----------------------------------------
Brad asked for a small metadata database (CSV is enough) to match
local HTML files to historical and current URLs.

Proposed approach (emailed 10 Oct 2026):
  1. Extract permalinks and metadata from the local HTML
  2. Reconcile against the Wayback Machine CDX index
  3. Search current sites (WordPress/Substack) for migrated copies
  4. Use content matching for unresolved cases

The constructed table:
  for_delong_url_metadata/delong_url_metadata.csv
  6,533 rows, 29 columns
  Share zip: delong_url_metadata_table.zip

Columns
  Identity
    local_id, source_zip, archive_directory, html_filename,
    original_local_path
  Extracted from HTML (filled)
    title, original_posting_datetime, original_posting_year,
    extracted_permalink, permalink_source, previous_post_url,
    next_post_url, movable_type_entry_id
  Live URL check (filled)
    live_url_status, live_http_status, live_final_url, live_checked_at
  Wayback (filled)
    wayback_status, wayback_url, wayback_timestamp, wayback_match_notes
  Current / migrated site (not invented)
    current_url, current_url_source, current_url_status
  Content match
    match_method, match_confidence, match_notes
  Working
    reconciliation_status, notes

Results
  Wayback found:     6,513  (earliest status-200 CDX capture of the permalink)
  Wayback not found:    20  (no capture in the CDX index; not guessed)
  Live URLs:         all broken/timeout on j-bradford-delong.net
  Current-site URLs: left not_checked (no verified 1:1 map yet)
  match_method:      url_exact where Wayback found the same permalink;
                     body text was not compared

Example Wayback URL:
  https://web.archive.org/web/20050103030326/http://www.j-bradford-delong.net/movable_type/2005-3_archives/000082.html

8. Preservation rules followed
------------------------------
- Never modified the original ZIPs
- Kept original filenames and paths
- Did not invent missing titles, dates, or current-site URLs
- Did not silently deduplicate
- Labeled uncertain dates (pre-2001 paper dates, trackback vs post)
- Preserved media URLs even when the files are not in the ZIP
- Transformations are scripts that can be re-run
